# MP 周报交叉分析器

## 描述
自动收集苏、褚玮、沈忆三人的周报，执行关键词提取和交叉分析，生成协同建议、隐藏商机、风险预警和情报共享报告。

## 触发条件
- 定时任务：每周一早上 9:00 执行（cron: `0 9 * * 1`）
- 手动触发：当用户说"分析周报"或"交叉分析"时

## 工具依赖
- GitHub CLI (`gh`) 或 Git 命令行
- 环境变量：`GITHUB_TOKEN`（需有 repo 权限）

## 执行步骤

### 1. 拉取最新周报数据
```bash
cd ~/.openclaw/workspace/mp-team-data
git pull origin main
```

读取三人本周的周报：
- `weekly/苏_{YYYY}W{NN}.md`
- `weekly/褚玮_{YYYY}W{NN}.md`
- `weekly/沈忆_{YYYY}W{NN}.md`

如果文件不存在，输出提醒：
```
⚠️ 沈忆的本周周报尚未提交，跳过其分析
```

### 2. 关键词提取
对每份周报提取以下类别的关键词：
- **客户名**：匹配客户档案中的 18 家客户名称
- **产品型号**：ALS/SFC/SFF/BXR/SRG 系列
- **区域**：东莞、苏州、青岛、浙江、昆山、厦门等
- **行业**：半导体、机床、新能源
- **动作**：报价、样品、交期、拜访、讲习会

### 3. 交叉匹配分析
执行以下匹配规则：

**协同建议触发条件**：
- 三人周报均出现"半导体" → 建议联合举办技术讲习会
- 两人以上提到同一客户 → 建议协同拜访

**隐藏商机触发条件**：
- 苏拜访东莞机床客户 + 褚玮负责TSB直线电机 → 建议导入TSB产品线
- 客户标签含"人事变动" → 建议重新接触沉睡客户

**风险预警触发条件**：
- 三人分别负责的客户均涉及同一产品（如SFC-050）→ 建议联合申请调拨
- 多个客户提到"交期"问题 → 预警供应链风险

**情报共享触发条件**：
- 三人分别通过不同代理店推进 → 建议建立代理店评估

### 4. 生成分析报告
输出格式：
```markdown
# 团队周报交叉分析报告

**分析时间**: {datetime}
**分析周期**: {week}
**参与人员**: 苏、褚玮、沈忆

## 一、关键词统计
| 人员 | 客户提及 | 产品提及 | 区域提及 |
|------|---------|---------|---------|
| 苏   | X次     | X次     | X次     |
| 褚玮 | X次     | X次     | X次     |
| 沈忆 | X次     | X次     | X次     |

## 二、协同建议
1. **[建议标题]**
   - 触发: {触发条件}
   - 内容: {具体建议}
   - 优先级: P0/P1

## 三、隐藏商机
...

## 四、风险预警
...

## 五、情报共享
...
```

### 5. 保存报告
将分析报告写入：
```
reports/weekly_analysis_{YYYY}W{NN}.md
```

然后提交到 Git：
```bash
git add reports/
git commit -m "weekly: 周报交叉分析 $(date '+%Y-W%V')"
git push origin main
```

### 6. 输出摘要到终端
```
=== 周报交叉分析完成 ===
发现 {N} 条建议：
- 协同建议: X条
- 隐藏商机: X条
- 风险预警: X条
- 情报共享: X条

详细报告已保存到:
reports/weekly_analysis_{YYYY}W{NN}.md
```

## 注意事项
- 如果某人未提交周报，在报告中标注"未提交"
- 分析结果仅供参考，最终决策由苏确认
- 报告文件不覆盖历史，每周生成新文件
